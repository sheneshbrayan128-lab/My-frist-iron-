# Product Photos — Status

All 40 products currently have a photo assigned (imgur-hosted, sourced from
photos you sent). "Additional Items" (catalog ref. 204–211) still uses a
generic placeholder photo since it's not a single specific product.

To swap or add a photo for any product, just send the direct image link
labeled with the product name — see `how-to-add-a-product-photo.md` if you
want to do it yourself via GitHub, or once Firebase is set up, use the
Image URL field in `admin.html` instead.
